# Installation

FQkit is a pure-Python package. Install it with pip.

## Requirements

- Python 3.9 or newer
- [NumPy](https://numpy.org) and [Matplotlib](https://matplotlib.org) (installed automatically)

## Install

```bash
pip install fqkit
fqkit
```

`fqkit` prints the FQKIT mark, with Felix and Dorcas underneath.

## Verify

```python
import fqkit
print(fqkit.__version__)   # 0.1.3
```

<Callout type="info">
  Everything here is free. The install is Python, and it brings NumPy and Matplotlib with it.
</Callout>

## Hardware extras

The core install does not include a vendor SDK. Add one when you want to
send jobs to a real machine:

```bash
pip install "fqkit[ibm]"       # IBM Quantum
pip install "fqkit[braket]"    # IonQ, Rigetti, IQM, AQT
pip install "fqkit[hardware]"  # both
```

See [Hardware](/docs/hardware) for the account, the runtime, and how to submit a job.
