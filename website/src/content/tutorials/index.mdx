# Tutorials

Hands-on lessons that teach quantum computing **one concept at a time** — each
with runnable [fqkit](https://github.com/Felixowusu20/Fqkit) code, the actual
output, a plain-language explanation, and the mathematics behind it.

## Lessons

- [The Bell State](/docs/tutorials/bell-state-lesson) — superposition,
  entanglement and measurement, from code to math.

## How to read a lesson

Every lesson follows the same structure:

1. **The idea** — what concept you are about to learn.
2. **The code** — a small, runnable fqkit program.
3. **The output** — what you see when you run it.
4. **The explanation** — why that output happens, in plain language.
5. **The math** — the linear algebra behind the scenes.

<Callout>
  Want to add your own lesson? Run the site locally and open the admin panel at
  `/keystatic` — write the lesson there and it is saved as an `.mdx` file under
  `src/content/tutorials/`, ready to commit and push.
</Callout>
