# API Reference

Everything below is importable from the top level:

```python
from fqkit import (
    QuantumCircuit, Qubit, Parameter, Gate,
    Identity, Hadamard, X, Y, Z, S, T,
    RX, RY, RZ, CNOT, CZ, SWAP, Toffoli,
    bind_parameters, run, apply_gate,
    probabilities, measure_all, measure, collapse,
    pauli, expectation, Hamiltonian,
    fidelity, states_equivalent, circuits_equivalent,
    run_density, to_density, Noise, purity, entropy, is_physical,
    to_qasm, draw, plot,
)
```

## QuantumCircuit

```python
QuantumCircuit(num_qubits: int)
```

- `.num_qubits`: number of qubits
- `.qubits`: list of `Qubit` objects
- `.operations`: ordered list of `Operation`s
- `.add_gate(gate, target_qubits)`: append a gate; validates targets
- `.to_qasm(measure=True)`: export to an OpenQASM 2.0 string
- `.draw(...)`: Matplotlib circuit diagram

## Gates

Factories return a `Gate`:

| Function | Returns |
| --- | --- |
| `Identity()` / `Hadamard()` / `X()` / `Y()` / `Z()` / `S()` / `T()` | 1-qubit |
| `RX(theta)` / `RY(theta)` / `RZ(theta)` | 1-qubit rotation |
| `CNOT()` / `CZ()` / `SWAP()` | 2-qubit gate |
| `Toffoli()` | 3-qubit gate |

## Simulation

```python
run(circuit, state=None) -> np.ndarray
```

Final statevector. Optional `state` sets the initial amplitudes.

```python
apply_gate(state, gate_matrix, num_qubits, target_qubits) -> np.ndarray
```

## Measurement

```python
probabilities(state_or_rho) -> ProbabilityTable
measure_all(state_or_rho, shots=1024, seed=None) -> MeasurementResult
measure(state_or_rho, qubits, shots=1024, seed=None) -> MeasurementResult
collapse(state, qubits, seed=None) -> (bitstring, new_state)
```

`print` on probability / measurement results shows formatted tables.
`plot(...)` draws bar charts for statevectors, `ProbabilityTable`, or counts.

## Parameters

```python
Parameter(name: str)
bind_parameters(circuit, param_values: dict, *, inplace=False) -> QuantumCircuit
```

Default binding returns a **new** circuit and leaves the template unchanged.

## Observables

```python
pauli("ZZ")
expectation(state_or_rho, observable) -> float
Hamiltonian(("ZZ", 0.5), ("XX", 0.25))
```

## Equivalence

```python
fidelity(a, b) -> float
states_equivalent(a, b, phase=True) -> bool
circuits_equivalent(a, b, phase=True) -> bool
```

## Density matrix & noise

```python
run_density(circuit, state=None, noise=None, noise_every_gate=False)
to_density(state)
Noise.depolarizing(p) / Noise.bit_flip(p) / Noise.phase_flip(p) / Noise.amplitude_damping(gamma)
purity(rho) / entropy(rho) / is_physical(rho)
```
