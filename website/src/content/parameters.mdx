# Parameters & Binding

A `Parameter` is a symbolic placeholder for a number. Parameters let you build a
circuit once and try many different angles: the foundation of variational
algorithms like VQE and QAOA.

## Define and bind

Binding is **immutable by default**: you get a new circuit back, and the
template keeps its symbols for the next angle.

```python
from fqkit import (
    QuantumCircuit, Hadamard, RX, Parameter,
    bind_parameters, run, measure_all
)

theta = Parameter("theta")

template = QuantumCircuit(2)
template.add_gate(Hadamard(), [0])
template.add_gate(RX(theta), [1])

bound = bind_parameters(template, {"theta": 3.14159})
print(measure_all(run(bound), shots=1024, seed=1))
# template is still unbound — safe to reuse
```

Legacy in-place binding (mutates the circuit) is available if you need it:

```python
bind_parameters(qc, {"theta": 1.0}, inplace=True)
```

## Unbound parameters

If you run (or export) a circuit that still has an unbound parameter, FQkit
raises a clear error instead of a confusing one:

```python
qc = QuantumCircuit(1)
qc.add_gate(RX(Parameter("theta")), [0])
run(qc)
# ValueError: Gate RX has an unbound parameter 'theta'.
#             Call bind_parameters(circuit, {'theta': value}) ...
```

<Callout type="info">
  You can also pass a plain number to a rotation gate (`RX(1.57)`) if you don't
  need a symbol.
</Callout>
