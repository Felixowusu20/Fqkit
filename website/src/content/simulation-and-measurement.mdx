# Simulation & Measurement

## Running a circuit

`run(circuit)` simulates the circuit and returns the final **statevector**: a
complex NumPy array of length `2**num_qubits`.

```python
from fqkit import QuantumCircuit, Hadamard, CNOT, run

qc = QuantumCircuit(2)
qc.add_gate(Hadamard(), [0])
qc.add_gate(CNOT(), [0, 1])

state = run(qc)
print(state)   # [0.707+0j 0+0j 0+0j 0.707+0j]
```

The circuit always starts in `|00...0>` and each operation is applied in order.
You can also pass an initial statevector: `run(circuit, state=...)`.

## Ideal probabilities

`probabilities(state)` returns the Born-rule table \(P(b)=|a_b|^2\) with **no**
sampling. Printing it shows a formatted table (not a raw dict).

```python
from fqkit import probabilities

print(probabilities(state))
```

## Measuring all qubits

`measure_all(state, shots, seed=None)` samples every qubit and returns a
`MeasurementResult` (dict-like counts, plus ideal vs empirical probabilities).

```python
from fqkit import measure_all

print(measure_all(state, shots=1024, seed=7))
```

## Partial measurement

Measure only some wires. Marginal probabilities are exact:

```python
from fqkit import measure, collapse

print(measure(state, qubits=[0], shots=1024, seed=1))

# Single shot + collapsed statevector
bit, psi = collapse(state, qubits=[0], seed=1)
```

Bitstrings follow the order of the `qubits` list (leftmost bit = first index).

## Plots

```python
from fqkit import plot, probabilities, measure_all

plot(probabilities(state), show=True)                 # ideal distribution
plot(measure_all(state, shots=1024, seed=7), show=True)  # shot counts
```

## Bit-order convention

<Callout type="warning">
  FQkit uses **big-endian** ordering: qubit 0 is the most significant bit of the
  bitstring. So the bitstring `01` means qubit 0 measured `0` and qubit 1
  measured `1`. Qiskit uses the opposite (little-endian) convention: see
  [OpenQASM & Hardware](/docs/openqasm).
</Callout>
